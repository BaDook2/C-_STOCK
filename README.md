# STOCK — 오프라인 테스트 / 온라인 투자

Windows x64용 `Stock.exe`를 실행하세요. .NET과 SQLite가 포함되어 별도 설치가 필요 없습니다.

## 바뀐 사용 흐름

- **오프라인 테스트**: 인증키 없이 한글 종목 이름을 검색하고 실제 과거 일봉으로 차트·백테스트·가상 매매를 이용합니다. 최초 다운로드는 인터넷이 필요합니다. 이미 저장한 종목은 조회 실패 시 캐시를 표시하며 수집 시각을 안내합니다.
- **온라인 투자**: 종목을 선택하고 **실제 계좌 키 설정**에서 증권사와 계좌를 선택해 연결합니다. 키움은 국내·미국, 한국투자·메리츠·토스는 국내주식을 지원합니다. 미래에셋·삼성·신한은 추가 연동 준비가 필요합니다. 매수·매도는 사용자 확인 후 선택한 한 계좌에만 시장가로 전송됩니다. 성공한 키는 Windows 사용자 계정에 암호화해 증권사별 저장하며 기본 온라인 계좌를 지정·변경할 수 있습니다.

국내/해외만 선택하면 거래소는 검색 결과에서 자동 매핑됩니다. 해외는 현재 미국 NASDAQ/NYSE/AMEX를 지원합니다. 종목 검색과 업종 이름은 네이버 공개 데이터, 국내 일봉은 네이버, 미국 일봉은 Yahoo Finance를 이용합니다. 공개 인터페이스는 공식 계약형 API가 아니므로 제공처 변경·제한·중단이 생길 수 있습니다. 실패를 합성 가격으로 대체하지 않습니다.

## 종목 · 차트

1. 국내 또는 해외를 고르고 `삼성전자`, `애플`, `엔비디아`처럼 이름을 입력합니다.
2. 이름을 입력하고 **Enter** 또는 **이름으로 검색**을 누르면 첫 결과를 자동 선택해 현재 주기로 차트를 표시합니다. 다른 종목을 클릭하면 바로 조회하며 로딩 상태를 보여줍니다.
3. 실제 캔들·거래량 차트가 나타납니다. 휠로 확대하고 드래그로 이동합니다. 마우스를 올리면 한국시간과 OHLCV를 표시합니다.
4. 이동평균선과 일목균형표를 체크해 표시합니다. 이동평균은 전략의 단기·장기 및 60일, 일목은 전환 9 / 기준 26 / 선행B 52입니다. 일목 구름은 실제 봉 범위 안에서만 표시해 차트 오른쪽에 빈 미래 슬롯을 만들지 않습니다.
5. 한국시간 날짜 범위와 가상 시작 금액(국내 원, 미국 달러)을 정하고 **백테스트** 또는 **모의매매 시작**을 누릅니다.

모의매매는 시작 날짜까지 차트를 보여줍니다. 매수·매도 후 **다음 거래일**을 누르면 다음 시가에 가상 체결됩니다. 재생은 수동 주문만 처리하며 전략 자동 적용은 제공하지 않습니다. 아직 진행하지 않은 가격은 표시하지 않습니다. 끝난 기간에서는 추가 주문하지 않습니다.

## 종목 골라보기

**목록 · 분야 불러오기**에서 시장별 시가총액 상위 종목(10/25/50/100개)을 가져옵니다. 국내·해외·전체 및 실제 제공처 업종 분류로 필터링한 후 **스크리닝 시작**을 누릅니다. 최신 확정 일봉에서 설정 조건이 맞는 종목만 표시합니다. 종목을 선택하고 **선택 종목 차트 열기**를 누르면 차트로 이동합니다.

이는 현재 상장된 상위 종목 목록에 대한 스크리닝입니다. 전체 시장이나 과거 시점의 상장 종목을 재구성한 목록은 아닙니다. 진행·조회 실패 건수를 표시하고 작업 취소를 지원합니다. 분류를 확인하지 못한 종목은 미분류로 표시합니다.

## 전략과 정기매수

현재 전략은 **국내주식 과매도·낙주 반등 일봉 백테스트** 하나입니다. 설정·프리셋·스크리닝·백테스트를 이 전략으로 통일했습니다. 구형 전략 선택/자동 복원/틱 자동 실행은 차단하고 기존 DB와 테스트 기록은 보존합니다. 실제 계좌의 수동 주문은 유지하며 자동매매는 지원하지 않습니다.

당시 종목 상태·실제 거래대금·위험·검증된 시장일 자료가 없으면 낙주 전략은 진입을 보류합니다. 자료 형식과 상세 계산은 [낙주 백테스트](docs/ui/OversoldBacktest.md)를 참고하세요. 현재 일봉 스크리닝은 별도 JSON 없이 기술적 조건을 평가하고 자료 미확인 후보를 구분합니다. 과거 백테스트 자료 요건은 유지하며 해외 종목은 제외합니다. docs/ui/CurrentDailyScreening.md 참고.

종목·차트 오른쪽에는 실제 계좌 주문 / 전략 백테스트 / 정기매수 백테스트 세 탭이 있습니다. **정기매수**는 매일·매주·매월, 시가·종가, 1회 금액·초기 투자금·수수료를 지정해 실행합니다. 정수 수량과 남은 현금을 반영하고 결과·평가곡선·매수 표시·테스트 기록을 저장합니다. 검증된 배당 자료가 없어 배당 재투자는 지원하지 않습니다. 오른쪽 패널은 최소 글자 크기 14로 표시하며 좁은 창에서 스크롤할 수 있습니다.

## 온라인 실제 주문

- 키움 REST API 실전 계좌 등록과 등록 IP가 필요합니다. 운영 호스트는 `https://api.kiwoom.com`이며 현재 화면에는 모의 계좌 연결 버튼이 없습니다.
- 주문 수량과 1회 매수 한도만 입력합니다. 가격 입력 칸은 없고 증권사 가격을 자동 조회해 확인창과 위험 검사에 사용합니다. 시장가이므로 실제 체결가는 다를 수 있습니다.
- 확인창에는 실제 계좌 마스킹 번호, 종목 이름, 매수/매도, 수량, 시장가, 조회 가격과 예상 금액을 표시합니다. 확인 중 조회 가격이 2% 이상 변하면 다시 확인하도록 중단합니다.
- 실계좌는 **직접 주문만** 합니다. 차트 전략은 실계좌 자동 주문을 하지 않습니다. 실제 계좌의 자동 손절·익절도 제공하지 않습니다.
- 주문/취소의 접수와 최종 체결을 구분합니다. **계좌 새로고침**으로 결과를 확인하세요. 응답 불명·취소 대기 시 신규 주문을 막고 자동 재전송하지 않습니다. 긴급중지는 신규 주문을 막고 미체결 취소를 요청하며 보유 주식의 자동 청산은 하지 않습니다.
- 잔고·내역·위험 기준은 현재 선택된 거래 시장 범위입니다. 전체 계좌의 국내·해외 통합 위험 한도를 보장하지 않습니다. 국내/해외 통화를 합산하지 않습니다. 1회 한도를 늘린 경우 키 설정을 통한 재연결 후 적용하세요.
- 실제 인증키로 계좌 연결·주문·취소를 검증하지 않았습니다. 작업 중 실제 증권사 주문을 보낸 적이 없습니다.
