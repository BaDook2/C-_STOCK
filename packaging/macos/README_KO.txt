STOCK · Apple Silicon용 macOS 앱

대상: Apple Silicon(M1 이후), macOS 14 이상.
.NET 런타임이 포함되어 있어 별도로 .NET을 설치할 필요가 없습니다.

설치
1. DMG를 열고 Stock.app을 Applications(응용 프로그램) 폴더로 드래그합니다.
2. 응용 프로그램 폴더에서 Stock.app을 더블클릭합니다.
3. ZIP을 받았다면 Mac에서 압축을 푼 뒤 Stock.app을 옮겨 실행합니다.

첫 실행 보안 안내
이 빌드는 무결성 검사용 ad-hoc 서명을 사용합니다.
Apple Developer ID 서명과 Apple 공증은 포함하지 않았습니다.
macOS가 차단하면 공식 릴리즈의 SHA256과 내려받은 파일이 일치하는지
확인하고 Apple의 앱별 실행 허용 안내를 참고하세요.
https://support.apple.com/102445
macOS 전체 보안 기능을 끄거나 터미널에서 격리 속성을 지울 필요가 없습니다.

자료·계좌
사용자 자료는 앱 번들 밖의 OS 사용자 저장소에 별도로 저장합니다.
API 키는 macOS Keychain에 저장하며 앱 파일에는 포함하지 않습니다.
Windows WPF의 키/DB를 자동 이관하지 않으므로 계좌를 다시 연결해야 합니다.
실계좌 주문은 명시 활성화 전까지 잠겨 있습니다.
이번 검증에서는 실제 돈 주문을 실행하지 않습니다.
