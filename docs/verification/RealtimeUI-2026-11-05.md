# 실시간 스크리닝·오프라인 차트 수정 검증 (2026-11-05)

## 변경

- `RealtimeScreeningWorkspace`: 종목별 UI 객체를 유지하고 속성만 갱신한다. 업데이트 시 선택과 더블클릭이 유지된다.
- `RealtimeScreeningNavigation`: 실행 서비스의 완성 봉·설정 snapshot과 확인된 체결을 읽어 기존 상세 창에 전달한다. 동일한 `IOversoldBacktestService`가 계산한 과거 모형체결은 출처로 구분하고 운영 계좌에 저장하지 않는다.
- 공통 `TradeOutcome`: 백테스트·가상·실계좌·원본 틱 차트의 익절/손절/청산 사유 캡션을 중앙 관리한다. 실제 체결 시각·가격과 거래 번호는 유지한다.
- 저장 전략 전환: 표 초기화 1회 → Background 지표 재준비 → 새 버전 행 갱신. 이전 버전의 큐 대기 UI 응답은 무시한다. 준비 중 새 완성 봉은 따라잡고, 이전 가상 보유분 보호는 유지한다. 새 전략의 자동매매는 감시를 다시 시작해 활성화한다.
- 중지 가능 시 옅은 빨강 버튼, 시장 상위 개수/조회 컨트롤 자리에 관심그룹, 공통 시장·분야 필터 유지.
- 오프라인 국내 차트에 공개 분봉·시간봉(1~59분, 1~12시간)을 연결한다. 화면 미완성 봉은 현재가 관측으로 갱신하되 일 누적 거래량을 분봉 거래량으로 대체하지 않는다.
- StockViewer `DefaultInterval=1초`를 읽어 비교했다. 선택 종목·공개 모의매매·공개 실시간 스크리닝도 장중 1초 조회로 변경했다. 마감·실패 쿨다운은 유지한다.

## 실제 장중 확인

삼성전자 공개 응답을 12:48:23.588, 24.603, 25.614, 26.620, 27.633 KST에 조회했다. 서버 관측시각은 각각 매초 전진했고 표본 가격은 205,000원으로 같았다. 제공처의 원래 pollingInterval은 7,000ms였다. 원본 체결이나 가격 변동이 매초 보장됨을 의미하지 않는다. 키·토큰·쿠키 없이 공개 API만 읽었다. 원본은 `artifacts/public-1second-20261105.json`이다.

실제 WPF 오프라인 창에서 삼성전자 현재가·시각 갱신과 1시간봉 표시를 확인했다. 시세는 13:03:04→12→22→34 KST 등으로 전진했고 가격도 변했다. 코스피+코스닥 상위10씩 총20종목 공개 실시간 감시에서 HLB 선택이 가격 갱신 후에도 유지됐고 더블클릭으로 1시간봉 상세 창이 열렸다. 검증 감시는 중지했다. 실주문은 수행하지 않았다.

## 자동 검사

`RealtimeScreeningUiRevisionTests`는 오프라인/가짜 온라인에서 행 객체·선택 유지, 공통 백테스트 서비스 및 설정 snapshot 전달, 실제 더블클릭 진입, 실제/가상 체결 봉 매핑, 전략 전환 1회 초기화와 이전 응답 차단, 중지 색·관심그룹 배치, 오프라인 분/시간봉을 검증한다. 실제 Windows 계좌 키를 테스트에 사용하지 않는다.
