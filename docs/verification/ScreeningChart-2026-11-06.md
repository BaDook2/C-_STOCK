# 스크리닝 차트 표시·실시간 시세·확대/축소 검증

## 구현과 원인

- 기존 `차트 주기` 시리즈 콤보를 읽기 전용 분석 기준으로 바꾸고, 표시 봉 선택은 분1~59/시간1~12·일/주/월 컨트롤로 분리했다. `지정봉` 탭으로 기존 숫자 재선택도 가능하다.
- `ScreeningChartViewModel`이 표시 상태/취소/캐시를 관리하고 `ScreeningChartData`는 기존 공개/연결 증권사 분봉 및 일봉 제공자를 사용한다. 전략·체결 snapshot은 변경하지 않는다.
- 실시간 가격/등락률은 기존 감시 snapshot에서1초마다 읽으며 전일 종가 기준·소수 둘째 자리다. 수신시각·지연·감시 중지 상태를 구분한다. 새 구독/주문/시세별 DB 쓰기 없음.
- 84개 시간봉→우클릭25봉 이후에도 기존 최소25봉 때문에 휠 확대가 막혔다. 확대 상태의 최소를5봉으로 낮추고 최초 확대25봉을 최대 축소 한도로 유지했다. 우클릭 포커스와 PreviewMouseWheel 입력도 보완했다.
- 기존 렌더는 모든 매매 표식/지지구간마다 전체 봉을 순차 탐색했다. 이진 탐색·배열/주기 캐시로 바꾸고 렌더 요청을 병합했다. 일목 OFF에서는 일목 계산을 생략한다.

## 동일 환경 성능 비교

20,000개 원본 분봉,160개 표식,1100×620 화면, 최대500봉 뷰포트에서20회 확대/이동. 매회 Dispatcher 렌더·레이아웃을 완료한 뒤 비트맵으로 캡처했다. 최초 캐시 준비는 제외했다. 이전 구현은 v0.1.11 소스의 클래스명/네임스페이스만 바꾼 격리 비교본이다.

| 측정 | 이전 | 수정 후 |
|---|---:|---:|
| 프레임 P50 | 6,896.49ms | 16.52ms |
| 프레임 P95 / 최대 | 7,107.11ms | 29.16ms |
| 20회 프로세스 CPU 시간 | 138,734ms | 484ms |
| 20회 누적 관리 할당량 | 8,908,468,912 bytes | 11,356,952 bytes |

할당량은 누적 임시 객체 수치로 실제 점유 메모리와 다르다. 화면 복사 비용도 포함한 해당 PC의 측정이며 모든 PC의 FPS를 보증하지 않는다. 새 구현 별도30회 측정은 P50 18.75ms / P95 22.86ms / 최대32.35ms였다. OnRender 호출 수로 매 샘플의 실제 재렌더를 확인했고 지표/표식 캐시 생성은 각각1회였다. 원본20,000봉은 그대로 유지했다.

## 기능·네트워크 검사

- 신규21항목: 읽기 전용 기준, 전체 기간,25→5봉 확대, 최초 확대 범위의 최대 축소, 잠금 상태의 휠 무시,7/15분 집계·시간 숫자 제한·일/주/월·지정봉 재선택, 원본 재사용, 가격/등락률/지연/중지, 늦은 응답 차단, 자료 미지원, 실제 재렌더·캐시/원본 보존, 실시간 봉 교체 후 같은 봉의 툴팁 갱신.
- 기존 관련 UI289항목 성공. 재렌더 계측과 툴팁 캐시 검사를 더한 최종 전체 회귀1,280항목 성공. 빌드 경고0/오류0.
- 온라인/오프라인 fixture의 실제 더블클릭→공통 팝업 경로에서 감시 snapshot의 가격/등락률 수신을 검증했다. 실계좌 주문·키 수정은 실행하지 않았다.
- 실제 네이버 공개 경로: 삼성전자005930 검색→신규 표시 봉 경로→2026-11-04 09:00~11-06 14:55의5분봉325개 수신. 증권사 호출/주문 없음. 실제 증권사 재인증/주문 검사를 했다고 주장하지 않는다.
- Windows 실제 마우스 조작: 일봉12봉↔지정봉84봉, 우클릭25봉, 휠10→5봉, 드래그 offset37→46, 포커스 확보, 실시간 검증 시세 갱신을 확인했다. 별도12봉 자료에서는 최대 축소12봉 한도도 확인했다. 테스트용 창은 정상 종료했다.
- 이전/다음과 창 종료는 로딩 취소와 generation으로 이전 결과의 재적용을 막는다. 창 종료가 실시간 감시를 중지시키지 않는다.

로컬 근거(Git 제외): artifacts/screening-chart-{build.log,checks.log,full.log,checks/,native-final/}, artifacts/chart-review-benchmark/{comparison.json,public-data.json}. 최초의 화면 복사만 재던 계측은 사용하지 않고 실제 렌더 완료 계측으로 대체했다.

## 배포

첫 전체1,279개/단일 EXE smoke 이후 검토에서 봉 교체/주기 변경 시 툴팁 캐시 무효화 누락을 발견해 수정했다. 수정본 전용21개/최종 전체1,280개/publish·EXE smoke도 성공했다. v0.1.12의 CI는 게시 전에 중단하고 새 v0.1.13으로 검증한다. 게시 전용 컴파일 지연을 고려해 CI 제한은45분이다(검사 단계 유지). 공개 파일 해시는 완료 시 TASKS/HANDOFF에 기록한다. 과거 SQLite11의 최초 유발 사건 미확정 항목은 별도로 유지한다.
