전체 시나리오 기대값·원본 합성 자료는 `Stock.Bins.Tests`의 Data/Pattern/Execution/Engine/Boundary/ExtendedChecks에 있다. 결과 JSON에는 각 ID·expectation·actual이 들어 있다. `replay-result.json`에는 신호/상태/주문/확인 체결·설정/자료/감사 해시·통화별 성과를 남긴다.

중요 경계는 미래·진행봉 제외 및 가용시각 되돌리기 방지, 증분 수식과 전체 이력 수식의 정확한 대조, 지지 허가의 독립 갱신/붕괴, 보유 중 박스 붕괴 기록, 잠긴 상단 돌파 전환 특례, 초기 부분체결/TP 수량/취소 후 잔량, Unknown 및 취소 확인 뒤의 늦은 체결, 당일 가족/포지션 설정 잠금, 통화별 현금 예약·손실 잠금이다. 동일 원본/설정/시계에서 직접 가상운용과 재생의 전체 감사 해시가 일치한다.

```sh
dotnet build STOCK.Avalonia.sln -c Release -p:UseSharedCompilation=false
dotnet run --project Stock.Bins.Tests -c Release --no-build -- artifacts/bins-tests
dotnet run --project Stock.Bins.Tests -c Release --no-build -- --validate-guide docs/strategy/Bins_Strategy_구현_검증_가이드_2026-11-11.md

dotnet build Stock.sln -c Release -p:EnableWindowsTargeting=true -p:UseSharedCompilation=false
```

초기 sandbox 복원에서 발생한 NuGet NU1900은 정상 권한의 `dotnet restore --force --no-http-cache`로 재조회한 뒤 해소했다. 최종 빌드에서는 해당 경고가 없다. 감사 검사를 끄거나 경고를 숨기지 않았다.

이 Mac에서는 Windows UI 실행을 하지 않았다. 실제 미국/한국 브로커의 원본 틱·세션/휴장·호가 규칙·취소·대사 지원과 시장 수익성은 미검증이다. Bin UI 연결·운영 저장 복원·새 앱 패키지/설치 교체·실계좌 전송은 이번 범위 밖이다. GitHub commit/push/태그/Actions/Release 없음, 실제 거래기록 삭제 없음.
