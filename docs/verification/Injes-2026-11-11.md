## 실제 제한과 후속 작업

1. 기존 미국 피드/parser가 당시 유효 TickSize, 거래정지, 뉴스 위험, RVOL 과거 동일 경과시간, 확인된 시장 단계·주문 권한, 필요한 L2를 모두 채워 주는지는 아직 실자료로 검증하지 않았다. 누락 시 MissingData로 진입을 보류한다. 현행 연결만으로 네 전략이 실제 시장에서 바로 거래 가능하다고 말할 수 없다.

3. Windows WPF UI 실행, 실제 Windows의 파일 선택/저장/계좌 보호 흐름은 해당 플랫폼에서 추가 확인해야 한다. Windows 배포용 패키지 생성과 GitHub 릴리즈는 수행하지 않았다.
