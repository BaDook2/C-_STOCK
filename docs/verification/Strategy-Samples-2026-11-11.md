사용자 요청에 따라 Inje4개와 Bin5개 매수 패턴의 전체 설정 샘플9개를 만들었다. **합성 자료를 사용하는 기능 검증이며 실제 시장 수익률 검증이 아니다.** 기존 배포 v0.1.18 이후 로컬 소스 검사다. 사용자 DB/설정/키/실제 거래기록·실계좌 주문·GitHub 게시·설치 앱 교체는 하지 않았다.

매수·매도 체결은 신호보다 나중 이벤트에서만 발생하며 수량이 일치하고 잔여 보유/미체결이 없다. 원본 이벤트 중복을 넣어도 거래·현금이 늘지 않는다. 호가 누락/미확인 세션·규칙은 거래와 후보 생성을 차단한다. 진입 이전 자료를 잘라 재생하면 미래 진입을 빌려오지 않는다(첫 이벤트에 진입하는 지지 전략의 빈 prefix는 제외; 미래 일봉/지지 자료 차단은 기존 Core 회귀에도 포함). ## 발견·보완

- Inje 연구 bridge가 SYNTHETIC/FIXTURE 출처를 replay의 SyntheticFixture에 전달하지 않던 표시 누락을 보완했다. 샘플 결과와 안내가 합성 검사임을 명시한다. 전략 수식/진입·청산/실제 주문 권한은 바꾸지 않았다.
- 실제 화면 검사에서 USD 관측 가격2.22가2 USD로 표시되던 기존 정수 내림 문제를 재현하고 수정했다. KRW 정수 표시·실제 계산 정밀도는 유지한다. 회귀 검사는 모든 샘플에서 관측된 USD 소수값이 표시되는지 확인한다.
- 스크리닝의 옛 공개 일봉 평가 안내를 원본 체결/호가·당시 확인 자료 기준으로 정정하고, Inje의 상승률도 표시하는 열 제목을 '급락률'에서 '기준 대비'로 바로잡았다.
- 초기 샘플에서 동일가 print가 호가 전략의 수동 대기 주문을 체결하지 않고, Bin 눌림목이 준비 기간/진입 시점 조건 부족을 거절하는 동작을 확인했다. 엔진을 느슨하게 바꾸지 않고 명시된 샘플 파라미터와 후속 체결/관측 자료를 맞췄다.

실제 경로는 `/Users/jang-gyeongbin/Library/Application Support/Stock.Avalonia/workspace.db`다. 설치 AppServices 경로와 대조하고 Stock 종료 상태에서 물리 경로·inode·크기102400bytes·integrity ok·행 수를 확인했다. 작업별 단기 연결 구조로 열린 DB 핸들은 없었다. 원본 state14개/다른 테이블0행/프로필2개였다.

SQLite backup API로 같은 데이터 폴더 `backups/20261111-strategy-samples/workspace-before-samples.db`에 원본을 보존했다. 독립 사본 저장 재현 후 설치 앱의 Stock.Core.dll에 있는 strict StrategyProfileJson/StrategyProfileStore로 실제9개를 저장하고 다시 읽어 모든 파라미터의 일치를 확인했다. 기존 `기본 설정`/`새 전략 설정` JSON과 현재 선택 `새 전략 설정`을 보존했다. state9개 추가와 목록 키1개 변경만 발생했고 나머지 기존 state 및 다른 테이블 전체 행은 동일했다.

`/Applications/Stock Development.app`를 실행해 전략 설정 상단 목록에서 기존2개/Inje4개/Bin5개를 모두 확인했다. 선택을 바꾸지 않았고 앱 시작 후 재검사도 integrity ok/프로필11/기존 상태·다른 테이블 동일이었다. 실제 백업 폴더 save-verification.json은 개인 자료로 Git에 넣지 않는다. 일회성 도구는 저장소 외부 `../work/save-strategy-samples`다. 설치 Core 참조 빌드 오류0, 네트워크 제한에 따른 NuGet 취약성 조회 NU1900 경고만 있었다.

제품 코드 변경이 없어 전체 회귀/릴리즈/앱 교체는 반복하지 않았다. 합성 시세·검증 거래 기록은 개인 DB에 넣지 않았다. 이전 개인 DB 미변경 설명은 격리 검증 당시이며 이번 명시 요청에 한해 프로필을 추가했다. 원본 시세가 필요한 실행 조건은 유지한다. 주간 잔여31%를 확인했고15% 보존 조건은 계속 적용한다.
