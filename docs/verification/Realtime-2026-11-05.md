# 2026-11-05 장중 실시간 검증

실제 국내 정규장에 Windows 사용자 PC의 Stock.exe와 현재 소스를 검사했다. 키·토큰·계좌번호는 출력하거나 저장소에 포함하지 않는다. 실제 주문 및 실계좌 자동매매는 실행하지 않는다.

## 공개시세 (오프라인)

- 삼성전자 종목 검색 후 당일 진행봉, 현재가, 전일 종가 대비 변동, 관측/수신 시각 표시를 확인했다.
- 실제 공개 현재가 응답의 `pollingInterval=7000ms`를 존중한다. 09:52:20 → 09:52:27 → 09:52:34 KST로 관측 시각이 전진했다. 같은 가격이 계속될 수 있으므로 가격의 변화만으로 갱신 여부를 판단하지 않는다.
- 당일 공개 1분봉 52개를 읽었으며 마지막 시작 시각은 09:51이었다.
- 실시간 스크리닝 KOSPI+KOSDAQ 상위 10개씩, 총 20개를 감시했다. 1분봉 마지막 분석이 09:51 → 09:52로 전진하고 공개 현재가가 바뀌었다. 저장된 `백테스트 검증 1 · 1일 보유` 설정에서 새 매수 신호가 표시됐다. 스크리닝 자동주문은 비활성 상태다.
- 1시간봉은 해당 시각의 봉이 완성되기 전까지 전일 마지막 확정봉을 표시하는 것이 정상이다. 실시간 가격 수신 시각과 봉 분석 시각은 다르다.

## 연결 증권사 (키움 국내 실전 서버, 조회 전용)

- 저장된 DPAPI 키로 OAuth·계좌·잔고 조회가 성공했다. 앱의 온라인 투자 진입도 기본계좌로 연결됐다.
- REST 현재가 3회 조회가 1초 간격으로 성공했다. 삼성전자 당일 조회에서 공식 1분봉 900개(과거 준비 자료 포함), 마지막 09:52를 받았다.
- 09:52:47~09:54:01의 75초 WebSocket 구독에서 실제 체결 1,197건, 호가 373건을 수신했다. 연결·등록 확인 후 정상 구독 해제했다.
- 종목·차트 일봉 화면은 키움 실제 체결과 1초 화면 반영을 표시했다. 1분 차트 조회도 성공했다.

## 장중 발견·수정 사항

1. 온라인 실시간 스크리닝의 과거 준비 봉에 대한 거래일 목록 누락으로 전략이 `검증된 시장 세션 자료 없음`에서 멈췄다. `LiveBatchSupport.WithObservedWarmupSessions`를 스크리닝·실시간 가상·실계좌 준비 경로에서 공유한다. 이미 입력된 장 시간은 보존하며 관측된 확정 봉의 날짜만 추가한다. 과거 종목상태/위험을 현재 값으로 보충하지 않는다.
2. 상태·위험 미확인 종목을 가상 자동주문 준비에 넣어 전체 연구 감시가 실패할 수 있었다. 검증된 종목만 가상 주문 서비스에 넣고 미확인 종목은 신호 연구 감시를 유지한다.
3. `IsTick`이 분봉까지 포함하는 기존 이름인데 현재가 헤더에서 이를 제외해 분봉 전환 시 과거 봉 기준 변동률·날짜로 바뀌었다. 실시간 현재가 헤더는 일/주/월/분/틱 화면에서 같은 관측값과 전일 종가를 사용한다.
4. 실시간 가상 실행을 중지하면 로컬 미체결 주문이 `CancelRequested`에 남아 새 시세를 기다렸다. `PaperBroker.CancelLocally`로 로컬 취소를 완료한 뒤 피드를 중지한다. 증권사의 실제 주문 취소/대사 경로는 변경하지 않는다. 대기 주문 생성→중지→미체결0/체결0/Cancelled 영속화를 추가 검사했다.

## 검증 경계

- 자동검사는 네트워크 없는 가짜 피드로 조건→신호→가상 대기주문→다음 실제 이벤트 역할의 모의 피드 체결→표식→중지/연결 장애를 검증한다. 실제 장중 구독 검증과 별개다.
- 이번 실제 계좌 연결 검사는 키움 국내다. 다른 증권사의 실시간 어댑터나 미국 장중 실시간 체결까지 검증했다고 보지 않는다. 기존 해외 잔고 권한 제약도 유지된다.
- 공개 시세는 원본 체결·호가가 아니며 지연될 수 있다. 공개 1분봉 거래대금은 OHLC 평균×거래량 근사값이고 완성봉만 전략에 전달한다.

## 수정 후 재확인 및 배포 검사

- 수정 EXE에서 온라인 20종목 구독 등록이 성공했다. 과거 준비봉 분석 시각 10:02에서 실제 피드로 완성한 10:05봉으로 전진했으며 행의 오류가 사라졌다. 종목 가격도 계속 변했다. 상태·위험 미확인은 별도로 표시하며 주문하지 않는다.
- 관심종목 탭을 열어 연결 계좌 현재가 조회를 확인하고 스크리닝으로 돌아와 같은 감시가 유지됨을 확인했다.
- 최종 헤더 수정 EXE에서 키움 1분봉 로딩이 성공하고 10:13:50→10:13:51 현재 시각·현재가·전일종가 대비 변동이 유지됐다.
- 공개 주봉/월봉 전환 후에도 10:31:53→10:32:00의 현재 관측 가격·전일종가 변동이 유지됐다. 시장 현황의 코스피/코스닥 장중 관측과 선택 종목 가격을 수신했고 10:32:40의 5초 조회 상태에 실패가 없었다. 지수는 공개 데이터 제공처의 관측 갱신 속도를 따른다.
- 오프라인 가상 전략의 공개시세 준비→Entry1→4주 지정가 대기주문을 실제 장중 확인했다. 팝업을 닫아도 실행이 유지됐다. 관측 가격이 지정가 체결 조건을 충족하지 않아 실제 장중 검사에서는 체결이 없었으며, 체결 표식은 결정적 가짜 피드 회귀검사로 검증했다. 테스트 후 전체 중지했다.
- Release 빌드 경고 0/오류 0. 전체 자동검사 **1,133개 통과**. 게시 단일 EXE smoke `Success=true`, `NoBrokerCalls=true`.
