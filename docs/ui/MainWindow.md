# 메인 화면

## 화면 목적
국내·미국 주식을 검색해 과거 데이터를 연구하거나 실제 계좌에서 직접 주문한다.

## UI 기능

| UI | 기능 | 실행 코드 |
|---|---|---|
| 오프라인 테스트 | 인증키 없는 과거 데이터·가상 매매 모드 | WorkspaceViewModel.IsOffline |
| 온라인 투자 | 저장된 기본계좌 자동 연결 또는 새 실제 계좌 연결 | WorkspaceViewModel.IsOnline → EnterOnline |
| 실제 계좌 키 설정 | 증권사 선택·연결, 성공 키 암호화 저장, 기본 계좌 변경 | Actions[키설정] → ConfigureKeys |
| 긴급중지 | 가상 대기 주문 취소 / 실계좌 신규 주문 차단 및 미체결 취소 요청 | Actions[긴급중지] |
| 작업 취소 | 현재 다운로드·스크리닝·백테스트 취소 | Actions[취소] |

## 동작 과정
저장·검증된 기본계좌가 있으면 온라인 라디오 선택 즉시 그 계좌로 연결하며 키 입력창을 다시 열지 않는다. 기본계좌가 없을 때만 실제 계좌 키 입력창을 연다. 인증 거부는 "실제 계좌 키가 아닙니다." 팝업 후 오프라인 복귀하고 통신 장애는 연결 실패로 별도 안내한다. 취소해도 오프라인으로 유지한다. 온라인 라디오 옆에는 연결 증권사와 마스킹 계좌번호를 표시한다. 키 설정 버튼은 두 모드 모두 사용할 수 있고, 오프라인에서 키를 검증해도 모드를 바꾸지 않는다. 중복 실행 중에는 잠시 비활성화한다.

실제 키는 연결 성공 후 증권사별로 Windows 사용자 계정에 암호화해 저장한다. 기본 계좌는 다음 온라인 전환의 사전 선택이며 실제 주문은 확인창에 표시한 현재 선택 계좌 한 곳에만 전달한다. [계좌 연결창](ConnectionDialog.md)에 지원 범위를 정리했다. 긴급중지는 현재 계좌의 미체결만 취소하고 보유 주식을 자동 매도하지 않는다.

온라인 모드는 주문 기능의 연결 상태만 바꾸며 과거 데이터 연구를 막지 않는다. 종목·차트의 전략 백테스트와 정기매수 백테스트는 오프라인과 온라인에서 동일한 엔진과 저장 전략으로 실행한다.

## 2026-10-11 공통 디자인

토스증권의 현재 웹 UI에서 밝은 회색 바탕, 흰 카드, 선명한 파란 주요 동작, 낮은 대비의 보조 문구, 넉넉한 여백과 둥근 컨트롤을 참고했다. 브랜드 화면을 복제하지 않고 이 앱의 기존 정보 구조와 기능명을 유지한다.

Styles/TossInspired.xaml이 색상과 공통 컨트롤 상태를 관리한다. TextBox와 ComboBox는 흰 바탕·10px 라운드·포커스 파란 테두리, CheckBox는 19px 파란 체크, 주요 Button은 파란색, 보조 Button은 옅은 회색이다. DataGrid는 흰 행과 옅은 hover/선택 색을 사용한다. 비활성 상태는 색을 낮추되 기능 상태는 기존 ViewModel 값을 그대로 따른다.

모든 ToolTip은 흰 배경, 짙은 글자, 옅은 테두리와 그림자를 사용한다. 화면에 직접 배치한 Button과 TextBox, 날짜 입력 내용은 세로 중앙에 정렬하며 TextLink 같은 사용자 지정 버튼 템플릿도 같은 정렬값을 사용한다.

최소 1160×760에서는 검색 190px, 주문/백테스트 350px를 확보하고 중앙 차트가 남은 폭과 높이를 사용한다. 입력 컨트롤 전역 스타일은 전략 설정의 명시적 180×32 숫자 입력 크기를 덮어쓰지 않는다.
