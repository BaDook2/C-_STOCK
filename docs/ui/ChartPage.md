## 동작 과정
검색 → 첫 결과 → 공개 일봉/지원되는 실제 계좌 데이터 → 캐시 → 선택 주기 차트.
빈 차트는 “데이터가 없습니다.”를 표시한다. 실제 체결 권한·연결이 필요한 경우에는 해당 안내 문구를 대신 표시한다. 단순한 동기 버튼은 화면 전체 Busy 상태를 켰다 끄지 않는다.

실시간 체결/시세가 들어오면 분·일·주·월봉 모두 같은 1초 화면 주기로 현재가와 진행 중 마지막 봉을 갱신한다. 원본 틱 이벤트는 매매 엔진 내부에서 유지하되 화면에는 틱 선택기·원본 틱 탭을 노출하지 않는다. 이벤트마다 WPF 차트를 다시 그리지 않고 1초 동안 들어온 값을 합쳐 한 번만 렌더링한다. 분봉에서는 이미 내려받은 마지막 분봉과 같은 구간의 실시간 체결을 병합해 Open/High/Low/Close/Volume을 교체하므로 과거 이력 배열이 새 가격을 가리지 않는다. 제공처가 새 시세를 보내지 않는 동안에는 같은 가격을 임의 생성하지 않는다.

종목명 아래의 등락 금액과 등락률은 차트에서 선택한 틱·분·일·주·월봉과 관계없이 항상 **전일 일봉 종가**를 기준으로 계산한다. 실시간 시세에는 제공처의 전일 종가를 사용하고, 과거 화면에서는 마지막 표시 일봉 바로 앞 거래일 종가를 사용한다. 따라서 주봉·월봉을 선택해도 주간·월간 봉끼리 비교한 값으로 바뀌지 않는다.

차트의 마지막 봉 위에서도 마우스 정보창에 날짜·시가·고가·저가·종가·거래량을 표시한다. 차트에서 표시하는 스크리닝 백테스트 매수·매도 점은 과거 자료의 모형 체결이다. 실제 계좌의 주문이나 체결로 표시하지 않는다.

현재 날짜 봉을 일괄 제외하던 문제를 수정했다. 차트는 제공처의 최신 봉을 보여주고 마지막 봉 시각을 표시한다. 기존 일봉 백테스트는 CompletedBars만 사용한다. 한국 15:40, 미국 현지 16:10을 보수적인 확정 기준으로 삼는다. 휴장일에 임의의 봉을 만들지 않는다.

선택 계좌가 해당 종목의 분봉 이력을 지원하지 않으면 분 선택기를 비활성화하고 이유를 안내한다. 키움 국내 연결에서는 `ka10080` 1분봉 이력을 받아 N분봉으로 묶는다. 원본 체결은 전략 실행·가상 체결·분봉 갱신에 계속 사용하지만 표시 전용 틱 선택기와 원본 틱 탭은 숨긴다. 저장된 실제 체결과 기존 틱 snapshot은 데이터 호환성과 매매 엔진을 위해 보존한다.

키움 차트 이력은 최근 연속조회 3페이지만 읽어 빠르게 첫 화면을 구성한다. 계좌·주문 조회의 완전조회 규칙과 분리되어 있으며, 추가 페이지가 있다는 이유로 이미 받은 차트 자료를 버리지 않는다. 틱·분봉 요청은 15초를 넘으면 시간 초과 이유를 표시한다. 우측 상단 긴급중지는 전체 화면이 로딩 중이어도 사용할 수 있고, 현재 차트 조회·공개 시세 갱신·지수/관심종목 조회·실시간 수신을 취소한 뒤 로딩 표시를 즉시 해제한다. 이후 사용자가 새 조회를 실행하면 API 요청이 다시 활성화된다.

위 최근 3페이지 제한은 종목/차트의 빠른 첫 화면에만 적용한다. 스크리닝 지정봉 상세는 실행 snapshot의 시작일~종료일을 재현해야 하므로 별도의 기간 조회를 사용해 종료일부터 시작일이 포함될 때까지 분봉 페이지를 가져온다. 오프라인 스크리닝에는 지정봉 선택을 표시하지 않고 일봉으로 고정하며, 온라인 연결 후 지정 봉은 분봉 1~59 또는 시간봉 1~12를 두 콤보박스로 선택한다. 과거 틱 snapshot은 상세 화면에서 읽기 호환한다.

우클릭으로 시작일을 종료일 뒤로 지정하면 시작일을 종료일로 맞춘다. 종료일을 시작일 앞으로 지정하면 종료일을 시작일로 맞춘다. 표시 시간과 기간 입력은 한국시간이다.

## 매매 기록

2026-11-05: 분·시간 차트는 오프라인 국내에서도 공개 1분봉으로 사용할 수 있다. 숫자·단위는 분봉 1~59 / 시간봉 1~12이며 선택 종목 장중 현재가는 1초 간격으로 조회한다. 처음에는 14일 범위의 분봉을 읽고, 당일 분봉은 분당 갱신한다. 현재가 관측은 화면의 미완성 봉 가격에만 합치고 일 누적 거래량을 분봉 거래량으로 사용하지 않는다. 원본 틱이나 백테스트 자료를 관측값으로 만들어 저장하지 않는다.

모든 공통 차트는 `TradeMarker.Reason`과 확인된 실현손익을 이용해 익절·손절 및 청산 유형을 표시한다. 축소된 묶음 표식에도 이 구분을 보존한다. 사유·원가 자료가 없는 오래된 수동 매도는 결과를 임의로 추정하지 않는다.
workspace-v2.db의 trade-marker:*에 확인된 모의·실계좌 체결 기록을 영구 보관한다. 모의 계좌와 실계좌 기록을 구분하고 실계좌는 증권사와 계좌 해시로 분리한다. 백테스트가 끝나면 현재 세션에서 `백테스트 매매 내역 표시`를 자동으로 켜고 차트를 해당 실행 기간으로 맞춰 표식이 즉시 보이게 한다. 다만 새 종목 검색 또는 앱 재시작 시 마지막 백테스트 선택·표시·실행 범위는 초기화한다. 저장된 테스트 결과는 테스트 기록 탭에 남으며 사용자가 명시적으로 선택할 수 있다. 1초 현재시세 갱신은 표시 중인 테스트 종료일 뒤 일봉을 붙여 표식을 압축하지 않는다. 세 표시 체크는 서로의 결과를 숨기지 않고 합쳐 그린다. 표식 또는 표식이 있는 봉을 한 번 클릭하면 출처·매수/매도·한국시간·가격·수량을 별도 팝업으로 표시한다. 실계좌 표시 중에는 5초마다 현재 선택 계좌의 주문/체결을 읽는다. 누적 체결 수량과 평균가를 보관하므로 개별 부분체결 전체 이력과 같지는 않다. 체결가/시각을 제공하지 않는 응답은 날짜 아래 * 표시로 구분한다. 주문가를 실제 체결가로 꾸미지 않는다. 앱이 관측하지 못한 과거 체결 전체를 복원한다고 보장하지 않는다.

백테스트 표식은 상세결과/판단기록의 거래상세목록과 같은 번호를 앞에 표시한다. 예를 들어 거래 3번의 분할매수와 부분매도는 모두 `#3 ▲ 매수`, `#3 ▼ 매도`로 표시된다. 표식을 선택한 상세 팝업에도 같은 번호가 나타난다.

차트를 크게 축소해 여러 표식이 겹치면 화면상 약 92px 구간을 기준으로 매수와 매도를 따로 묶어 `#3,#4 ▲ 매수 2건`처럼 포함 거래번호와 건수를 표시한다. 이는 화면 표현만 묶는 것이며 개별 체결 시각·가격·수량과 저장 기록은 삭제하거나 합치지 않는다. 같은 규칙을 종목/차트와 스크리닝 백테스트 팝업에 적용한다.

봉 차트는 어느 위치에서 눌러도 포인터를 캡처해 좌우로 이동한다. 오른쪽으로 밀면 과거 구간이, 왼쪽으로 밀면 이후 구간이 나타난다. 확대되어 한 봉 폭이 넓어도 12px 이내 이동 단위로 반응하며 4px 이내 움직임은 표식 선택을 위한 클릭으로 처리한다.

마우스 휠 확대·축소는 포인터가 가리키는 봉을 기준으로 한다. 확대 전 포인터 아래에 있던 봉이 확대 후에도 같은 화면 위치에 남도록 표시 시작 위치를 함께 보정하며, 오른쪽 마지막 봉을 고정 기준으로 사용하지 않는다.

긴 분봉·시간봉을 축소해 이동할 때도 드래그 거리는 실제 화면상 봉 폭에 비례한다. 봉 폭이 1px보다 작아도 1px로 강제하지 않으므로 손가락이나 마우스를 움직인 거리만큼 자연스럽게 이동한다. 이동평균선과 일목균형표는 봉 배열 또는 설정이 바뀔 때만 다시 계산하고, 드래그 중에는 WPF 렌더 요청을 화면 프레임당 한 번으로 합친다.

여러 봉이 같은 화면 픽셀에 겹치는 최대 축소 구간에서는 화면 표시용으로만 약 1.5px 단위의 OHLCV 열을 만든다. 시가·종가·고가·저가·거래량을 보존해 그리며 원본 분봉·시간봉 배열은 줄이거나 삭제하지 않는다. 확대, 마우스 정보, 매매 표식, 백테스트에는 원본 봉을 계속 사용한다.

2026-11-06: 공통 CandleChart의 매매 표식/지지구간 봉 위치는 이진 탐색과 배열·주기별 캐시를 사용한다. 휠/드래그는 렌더를 프레임 단위로 병합하고, 일목이 꺼져 있으면 해당 계산을 건너뛴다. 스크리닝 팝업만 우클릭 확대 후 최소5봉·최초 확대 봉 수까지의 최대 축소 제한을 사용한다. 종목/차트 탭의 일반 확대 범위는 유지한다. 상세: [스크리닝 차트](ScreeningBacktestPopup.md).

## 2026-11-07 기준/표시 갱신

- 차트 데이터 선택은 오프라인 일봉, 온라인 분1~59/시간1~12 지정봉·일봉이다. 주봉/월봉/틱 표시 선택기는 제거한다. 과거 기록에 보존된 자료는 삭제하지 않는다.
- DisplayNumber.Price는 decimal.Floor 후 천 단위 정수로 표시한다. 미국도 같은 표시 정책이며 원본 OHLC/체결/주문/손익 계산의 decimal 값은 변경하지 않는다. %는 기존 소수 둘째 자리 표시를 유지한다.
- 매도 표식은 알려진 RealizedPnl을 부호와 함께 표시한다. 축소 표식 묶음은 모든 구성 매도의 손익이 알려져 있을 때 합계로 표시한다. 클릭 안내도 실현손익/통화를 표시한다. 실계좌의 원가·비용이 없어 손익을 확인할 수 없는 표식은 미확인으로 안내하며 임의 계산하지 않는다.
- 실제 계좌/가상 계좌/전략 백테스트/정기매수 백테스트는 우측 UniformGrid2열×2행으로 정렬한다. 좁은 패널의 지정봉 입력은 다음 줄로 감싸고 전체 폭에 맞춘다.
- 공통 TossInspired.xaml의 ScrollBar 템플릿은 양방향 Track/Thumb/페이지 이동을 유지하면서 얇은 회색 둥근 막대로 표시한다. 모든 ScrollViewer/DataGrid/TextBox/팝업에 적용한다.

## 온라인 지정봉 선택기 복구 (2026-11-07)
