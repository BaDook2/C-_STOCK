# 전략 D · 당일 반복매매 — 1차 사용 안내

기존 `krx-oversold-rebound` 전략과61개 설정은 그대로 유지한다. 새 전략은 `strategy-d-intraday-v1`/schema2이며 자동 활성화하지 않는다. **실계좌 주문 어댑터는 아직 연결하지 않았다.** 아래 실행은 가상 계좌 또는 연구다.

## 여는 위치와 저장

- 전략 설정 → **전략 D · 간편/고급 설정**: 한국어 항목/단위/도움말, enum 선택, 설정 추가·저장·복구·JSON 불러오기/내보내기.
- 종목·차트의 전략 백테스트 → **전략 D 백테스트**: 현재 검색한 국내 종목.
- 스크리닝 → **전략 D 스크리닝·가상**: 현재 시장 목록/선택 관심그룹, 중복 제거, 국내 최대100종목 연구. 기존 일반/실시간 스크리닝의 전략 목록을 D 설정으로 덮어쓰지 않는다.

`daytrading-definitions-v2`에 D 설정만 저장한다. 구 `oversold-*` 키/JSON/활성 선택은 바꾸지 않는다. 이름을 바꿔 저장하면 별도 D 설정으로 보관된다. 불러오기는 편집값만 바꾸며 저장하기 전에는 기존 값을 덮어쓰지 않는다. 고급 JSON의 `IndicatorTimeframes`도 import/export로 유지한다. UI가 없는 향후 정책은 임의로 다른 전략으로 해석하지 않는다.

간편 설정은 공통 핵심 수치와 기본 분석/매물대/보호/계좌 한도를 표시한다. 고급 설정은 급락 OR/AND·후보 기간·반복 진입·자료 품질을 포함한다. OFF한 조건의 수치는 보존되며 엔진에서 적용하지 않는다. 저장/연구/실행 전에 전체 validation을 수행한다. 수수료는 **0.015% 그대로** 표시·저장하며 두 자리 표시로 저장값을 바꾸지 않는다.

## 계산 흐름

1. 당시에 알려진 확정 일봉/분봉과 `HistoricalFacts(KnownAt)`를 준비한다. 기본 MA240은 **전일 확정 일봉240개**다. 분봉 선택으로240분선이 되지 않는다.
2. 일봉 중기/단기 낙폭과 당일 고점/rolling 고점 하락을 설정한 OR/AND로 결합한다. 미래 일봉 고가/종가·미확인 원본 체결을 사용하지 않는다.
3. MA와 거래량 매물대의 이질적 중첩을 검사한다. MA 여러 개만으로 통과하지 않는다. 최대 거리/zone 폭/추격 거리를 별도 검사한다.
4. 유효 지지 접근 이후의 실제 관측 가격을 저점으로 추적한다. 저점 대비 반등 기준을 **새롭게 상향 통과**했을 때 한 번만 신호를 만든다. 안정적인 물리 zone/episode 식별로 작은 매물대 갱신에 후보를 리셋하지 않는다.
5. 동일 `StrategyDRuntime` → 공통 `DayTradingPortfolioEngine` → 실행 어댑터. 신호/주문/체결을 구분한다. 확인 체결만 수량/평균단가/TP 단계를 바꾼다. 예약현금·계좌 공통 노출/일손실/연속손절/진입횟수/종목 위험예산을 적용한다.
6. 고정/지지/추적/선택 본전 보호와 전량/분할/추적 중심 익절을 처리한다. 동시에 발동하면 보호 주문 한 건을 만들고 다른 조건도 근거에 남긴다. 청산 전까지 현재 최고가/stop을 불리하게 낮추지 않는다.
7. 독립 시계로 신규 진입 종료·당일 청산 요청을 처리한다. 후속 체결이 없으면 미체결로 남는다. 청산 보장을 표시하지 않는다. 미청산 보유를 새 빈 계좌로 숨겨 재시작하지 않는다.

## 백테스트와 자료 한계

- **수집 원본 이벤트 재생**: 현재 프로세스 메모리의 KIWOOM 원본 체결·수신시각이 있어야 한다. 받는 순서 그대로 동일 런타임에 주입한다. 원본 호가가 없으면 호가 체결을 만들지 않는다. 수집이 없으면 명확한 자료 오류다. 공개 가격 폴링/증권사 OHLC를 원본 틱으로 바꾸지 않는다.
- **확정봉 근사**(기본): 완성 분/시간/일봉에서만 반등을 평가하며 다음 봉 시가+지연에 가정 유동성으로 체결한다. 실제 틱 저점/첫 접근 시각/High와Low 선후를 재현하지 않는다. 같은 봉에서 stop과TP가 가능하면 stop 우선이다. 이 입력은 `ResearchOnly`이며 실계좌 경로로 전달할 수 없다.
- **봉 연구 가정 허용**: 기본 OFF. 켠 연구에서만 관측 OHLC 일자의 정규장 시간, 거래대금 OHLC평균×량, 미확인 일반주식/위험없음을 가정한다. 휴장·단축장 달력이 아니며 알려진 위험은 덮어쓰지 않는다. 실시간 가상 시작은 이 가정을 가져가지 않는다.
- 오프라인 자료 기준은 일봉, 온라인 과거 자료는 연결 증권사 분/시간봉이다. 체결 수/초 기준은 원본 이벤트가 필요하다. 원본 부재·정밀 매물대 부재·당시 위험/시장일 미확인은 성공이나0수익 결과로 위장하지 않는다. 거래0건이더라도 결과의 마지막 종목 상태/자료 사유를 확인한다.

연구 결과는 당시 봉·설정·신호·확인 체결·지지 snapshot·모형/출처·비용/성과를 보관한다. `IntradayBacktestService`의 typed 요청은 전체 설정/자료/facts/비용/기간으로 cache를 구분한다. 원본 틱을 DB에 저장하지 않는다. `테스트 기록`에 **전략 D** 실행 기록이 추가되며 더블클릭하면 당시 결과/차트를 연다.

## 실시간 가상 실행

온라인 키움 국내의 원본 스트림을 사용한다. 1차 호스트의 구독 범위는 **최대20종목**이다(기존 전략의100종목 기능은 변경 없음). 당시에 확인된 오늘 세션/종목 상태·위험 입력이 필요하다. 현재 parser는 거래소 날짜를 추정하는 품질을 명시하므로 기본 `거래소 시각 확인 필수`에서는 신규 진입이 차단될 수 있다. 완화 여부는 고급 설정에서 사용자가 결정하며 실제 주문 허가가 되지 않는다.

**신규·추가매수 허용**은 기본 OFF. ON 이후 새 신호만 가상 주문한다. OFF는 새 진입/추가매수만 막고 기존 보유 보호를 유지한다. 실행 설정은 snapshot으로 고정한다. 팝업을 닫아도 앱 수명 서비스/독립 시계/피드는 유지되고 다시 열면 현재 상태를 표시한다. 팝업 긴급중지·기존 다중매매 전체 중지·메인 긴급중지는 D에도 연결된다. 긴급중지는 보유분 임의청산 없이 새 전략주문을 차단하고 미체결 취소를 요청한다.

시세 수신은 bounded channel, 계산은 background serial consumer, UI는1초 간격 snapshot 갱신이다. 처리 지연은 시세 freshness 검사로 신규 진입을 차단한다. 종목 오류는 종목 상태, 피드 오류는 연결 종료/신규진입 차단으로 표시한다. 보호 감시 종료/미체결/보유 상태를 프로그램 종료 전에 안내한다. 재동기화와 실계좌 adapter/원본 시각 보증을 완료하기 전 실제 주문으로 확장하지 않는다.

## 차트와 근거

기존 `CandleChart`를 재사용한다. 실제 체결 시각/가격의 매수·매도와 진입 당시 MA+volume zone을 별도 층에 표시한다. 봉은 OpenTime으로 표시하여 분/시간봉 체결이 한 봉 밀리지 않게 했다. 한 번 클릭하면 해당 체결 행·실현손익·한국어 사유와 원래 신호/청산 snapshot을 표시한다. 축소 시 기존 표식 병합, 마우스 위치 확대/드래그 이동도 그대로 사용한다. 실시간 가상 체결은 기존 메인 차트의 모의매매 체크박스에도 연결한다.
