# 전략 설정 통합 · 2026-11-09

사용자 후속 요청(2026-11-10)에 따라 Avalonia 전략 설정의 순서는 `백테스트 전용 → 급락 판단 전략 → 공통 전략 조건`이다. `시점별 검증 자료 (고급)` 상위 영역과 `당시 종목 상태·위험·시장 세션 JSON` 수동 입력창은 전략 설정에서 제거했다. 다른 D 설정/연구/실시간 탭과 진입 버튼은 제거했으며 과거 D 결과는 결과 전용 창으로 열 수 있다.

`사용` 체크박스는 급락 판단 전략 제목 옆에 있어 접힌 상태에서도 바꿀 수 있다. 체크박스 클릭은 펼침 상태를 바꾸지 않는다. 사용 OFF여도 모든 하위 그룹의 펼침/접기는 작동하고 입력 편집만 비활성화한다. 기존에는 그룹 목록 전체를 비활성화해 하위 펼침 버튼까지 막혔는데, 비활성화 범위를 각 그룹의 입력 영역으로 좁혔다. 제목 안 체크박스는 해당 Expander에만 적용한 hit-test 스타일로 클릭을 받는다. 시점별 자료 모델·내부 검증·기존 저장 설정은 그대로 유지한다.

## 선택·저장

- `사용` OFF: 기존 과매도·낙주 전략을 사용한다. 기존 프리셋은 OFF로 읽힌다.
- `사용` ON: 기존 D 데이터·신호·포트폴리오 엔진의 전체 진입·청산 규칙을 사용한다. 단순 급락 필터 추가가 아니다.
- 선택과 D 설정, 지표별 봉 단위는 기존 전략 이름에 함께 저장·복구·JSON 왕복된다. 이전 별도 D JSON도 기존 `불러오기`에서 가져올 수 있다.
- D 영역에는 총 투자금·편도 수수료·매도 거래세·체결 슬리피지 입력을 중복 표시하지 않는다. 기존 전략의 투자금/비용을 공통으로 사용한다.
- 기본 분석의 크기와 단위는 한 줄에 붙인다. 입력 옆 범위/단위 설명은 제거하고 도움말로 유지한다.

2026-11-10 JSON 점검: 기존/D의 동일 단위를 유지할 때 가져온 봉 크기를 보존한다(예:5분·3시간). 단위를 새로 고르면1부터 시작한다. 알 수 없는 항목명·중첩 중복 키·잘못된 기간 키는 오류로 표시하고 등록/현재값을 바꾸지 않는다. OFF인 D도 저장 전에 검증한다. 숫자 enum 내보내기는 유지하고 영문 enum 이름 가져오기도 지원한다. 상세 형식과 기본값은 [현재 전략·JSON 설명서](../strategy/현재_전략_상세설명_및_JSON_가이드_2026-11-10.md), 검사 근거는 [JSON 검증](../verification/Strategy-JSON-2026-11-10.md).

## 봉 단위와 입력

기존 `봉` 기간 입력은 숫자와 같은 너비의 `분 / 시간 / 일봉 / 주봉 / 월봉` 콤보를 사용한다. 이동평균 기간 목록 입력은 보존하고 옆의 `봉 목록` 설명을 `일봉 / 주봉 / 월봉` 콤보로 대체한다. 기간 숫자는 해당 단위의 봉 개수다. 온라인의 판단 입력은 화면의 데이터 기준과 분리해서 준비한다. 필요한 최소 분봉으로부터 완성된 독립 지표 봉을 집계하며 아직 확정되지 않은 주봉·월봉이나 미래 KnownAt 자료는 사용하지 않는다.

오프라인 백테스트·스크리닝은 일봉으로 계산한다. 이 안내는 설정 화면 맨 아래에 표시한다. 일봉 자료는 당일 운용의 장중 진입/청산 순서를 재현하지 않으므로 D의 시각·후보 유효기간 조건을 충족하지 못하면 거래가 나오지 않는다. 조건을 임의로 끄거나 장중 체결을 만들어 내지 않는다.

정수 값에 강제로 붙이던 `.00`을 제거했다. 기간·횟수는 원래 정수 검증을 유지하고, 비율 및 기존 수수료 `0.015` 등 실제 소수 값은 반올림하거나 정수로 덮어쓰지 않는다.

## 차트

- 검은색 MA240은 실제 일봉 240개의 종가 평균이다. 다른 표시 주기를 선택해도 240분선 등으로 바꾸지 않는다.
- 짧은 백테스트 결과에도 전체 준비 자료를 전달한다. 일봉 준비가 부족하면 가짜 240선을 만들지 않는다.
- D 매수에 실제 사용된 신호의 `ReboundLow`를 보라색 가로선과 `급락 판단 지점` 이름으로 표시한다. 주문 의도만 있는 미체결 신호는 이 선의 근거로 쓰지 않는다.
- D 가상 체결 마커에도 당시 저점을 보관하여 메인 차트에 반영한다. 일봉선과 저점선이 가격 영역 밖으로 가려지지 않도록 표시 범위에 포함한다.

## 실행 연결

일반 백테스트와 스크리닝은 저장한 알고리즘 선택을 따른다. 원본 체결 D 가상 실행은 기존 `가상 계좌 전략 실행`에서 시작하고 공통 D 세션·위험·재진입·청산 엔진을 재사용한다. D 원본 실행에는 온라인 키움 국내 체결 피드와 확인된 시점별 자료가 필요하다. 공개 REST 관측 기반 실시간 스크리닝은 봉 근사 연구이며, 이 경로의 자동매매가 D 대신 기존 전략을 실행하지 않게 차단하고 가상 계좌 실행 위치를 안내한다. 기존 전략과 D의 혼합 가상 배치는 서로 다른 실행 방식이므로 각각 시작해야 한다. D 실계좌 주문 연결은 기존과 같이 지원하지 않는다.
