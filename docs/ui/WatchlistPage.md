# 관심종목

## 화면 목적
종목을 그룹별로 저장하고 공개 시세와 차트를 빠르게 확인한다.

## UI 기능
| UI | 기능 | 실행 코드 |
|---|---|---|
| 차트 위 그룹 선택 + ☆/★ 관심등록 | 선택 종목을 지정 그룹에 등록. 현재 그룹에 등록되면 별을 공통 파란색으로 채움 | RegistrationGroup / IsWatchRegistered / 관심등록 |
| 그룹명1·그룹명2 | 기본 그룹. 탭처럼 선택해 그룹별 목록 조회 | WatchGroups / SelectedWatchGroup |
| 그룹명 옆 작은 편집 | 이름 입력칸 열기, 저장·취소 | WatchGroup.Edit / 그룹저장 |
| + 그룹 추가 | 다음 번호의 기본 이름으로 새 그룹 추가 | 그룹추가 |
| 시세 새로고침 | 현재 그룹 종목의 공개 가격·등락 조회 | RefreshWatchlist |
| 차트 열기 | 선택한 관심종목의 데이터 가져오기와 차트 이동 | 관심차트 |
| 이 그룹에서 해제 | 현재 그룹의 선택 종목만 제거 | 관심해제 |

## 동작 과정
등록·그룹 변경 → WatchlistViewModel → TradingStore 상태 watch-groups 저장.
앱 시작 → 그룹 ID·이름·종목 복원 → 관심종목 탭 진입 / 그룹 선택 → 공개 시세 조회.
그룹명은 1~20자이며 공백만 있는 이름·제어문자·중복 이름을 거부한다. 같은 종목은 여러 그룹에 등록할 수 있고 동일 그룹에서는 중복 등록하지 않는다. 해제는 다른 그룹에 영향을 주지 않는다. 현재가와 등락은 정수 표시이며 통화와 실제 시세시각을 표시한다. 시세 실패는 해당 행에 표시하고 이전 값의 시각을 유지한다. 그룹을 바꾸면 완료 중인 조회를 원래 종목에 반영한 뒤 새 그룹을 조회한다.
