# 기존 화면의 Inje 연결

2026-11-11 로컬 소스 기준. 탭/창/버튼을 추가하지 않았다. 구전략 D 전용 창/버튼은 사용자 최신 지시로 제거했다. 이 문서는 현재 흐름을 설명하며 과거 61개/D 설정 문서는 이력이다.

## 설정

기존 selector에서 네 전략을 고른다. 기존 추가/이름변경/저장/복구/불러오기/다운로드/기본값을 그대로 쓴다. 배치는 백테스트·체결 가정 → Inje 전용 설정 → 공통 조건이다. 같은 기존 카드 안의 Standard/Advanced 선택으로 전용6개 강도 또는 상세10/12/11/13개를 펼친다. 모드 콤보의 초기 null 값은 그룹을 재생성/닫지 않으며 실제 모드 변경만 재구성한다.

공통 14개와 비용/초기 현금 10개, 선택 전략 전용값을 새 Core 필드에 연결했다. 정수는 분수 개수를 거절한다. USD 가격·%·배수·수수료는 소수 정밀도를 보존한다. 수동 종목상태·위험·시장세션 JSON 영역은 없다. 해당 자료는 공급 어댑터가 당시 시점으로 제공하며 미제공 시 MissingData다.

Avalonia: StrategyEditor / StrategyPanel / SettingInput. WPF: OnlyOversoldWorkspace / OversoldWorkspace / ParameterField / OversoldParameterPanel. 이름변경 시 이전 native key를 제거하고, 다음 시작 때 삭제한 원래 기본 이름을 다시 중복 추가하지 않는다.

## 연구와 실행

백테스트와 스크리닝 버튼은 InjesResearchBridge의 원본 이벤트 경로를 사용한다. 기존 차트의 표시 주기 선택은 알파 파라미터를 바꾸지 않는다. 일봉만 있을 때 백테스트를 성공한 척하거나 구전략으로 재시도하지 않는다. 스크리닝은 Universe/Attention/Strategy/Risk의 네 단계를 표시하고 실제 주문 없이 평가한다.

기존 가상 실행 팝업의 종목·전략·예산 목록을 사용한다. 미국 USD 종목을 추가하고 모든 행의 알고리즘/파라미터가 같아야 시작한다. 팝업을 닫아도 앱 소유 스트림은 유지된다. 보유/매수대기/매도대기/재진입대기 행은 후보 필터 때문에 숨기지 않는다. 기존 실제 계좌 전략 시작은 명시 잠금이며 계좌 수동 주문 승인만으로 활성화되지 않는다.

기존 복원/이전확인 동작은 Inje 원장과 고정된 정의를 복구한다. 기존 표에 종목과 수량을 표시하며 신규 매수 OFF다. 보호 재개는 같은 정의로 새 피드를 열고 창/미완성 후보를 다시 준비한다. 중지는 새 매수만 막고 보유 보호를 유지하며 flat이면 세션을 끝낸다. 개별 중지는 해당 종목만 차단한다. 긴급중지/종료는 원장을 보존하고 임의 청산하지 않는다.

## 차트와 기록

기존 live 차트는 원본 체결의 표시용 1분 집계를 사용하고, 확인된 가상 체결만 표식으로 찍는다. 체결 선택 시 기존 상세 영역에서 native 신호의 시각·source/sequence·조건·계획/실제 가격·차단 이유를 표시한다. 지지 전략은 진입 당시 군집·근거를 고정해 표시한다. USD 가격 축·가이드·체결 표는 필요한 소수 정밀도를 보존한다. 검은 240일선 등 기존 공통 표시 지표는 충분한 완료 일봉이 있을 때 유지한다.

WPF 실시간 차트의 기존 KRX/구전략 호출도 native 원장으로 교체했다. 기존 테스트 기록은 새 Inje 연구 snapshot을 사용하며 D/구전략 전용 기록은 최초 migration으로 정리한다. 계좌 키/관심종목/정기매수/실제 주문 안전 기록은 보존한다.
