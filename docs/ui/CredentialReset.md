# 실제 계좌 키 설정 (2026-10-05)

선택 화면에는 키움·한국투자·메리츠·토스 4개만 표시한다. 미래에셋·삼성·신한의 기존 저장 파일은 자동 삭제하지 않는다.

- **키 표시**: App Key/Secret 동시 표시·감춤. 기본과 창 재열기는 감춤. 전환 중 편집값은 동기화하며 닫을 때 입력 컨트롤을 비운다. 표시 상태에서도 복사·잘라내기는 차단한다. 붙여넣기는 가능하다.
- 제목 오른쪽 **모든 API키 초기화**: 숨긴 증권사를 포함해 계좌키 저장소의 알려진 브로커 암호화 파일과 기본 계좌 선택만 초기화한다.
- 연결 버튼 오른쪽 위 **API 키 초기화**: 현재 선택한 증권사만 초기화한다.
- 두 버튼 모두 앱 내 범위 확인에 동의해야 실행된다. 취소하면 저장키/세션/입력은 변하지 않는다. 기존 키 설정 창을 열 때 실행 중 연결을 정리하는 정책은 유지된다.
- 활성 계좌에 해당하면 신규 주문을 차단하고 진행 중 작업과 감시를 정리한 후 키를 삭제한다. 이미 접수된 주문을 미전송으로 바꾸거나 보유분을 시장가 청산하지 않는다. 주문 대사 기록·거래 DB·시세·전략 설정은 삭제하지 않는다.
- 저장은 기존 DPAPI CurrentUser를 사용한다. 브로커 Dispose 때 토큰 참조를 해제한다. .NET 불변 문자열의 물리적 메모리 즉시 소거를 보장한다는 의미는 아니다.

`ConnectionDialog → CredentialResetService(확인) → Workspace.PrepareCredentialReset → RemoteTradingSession.Revoke / StopMulti → BrokerCredentialStore.Delete/DeleteAll`.

검증은 테스트 임시 디렉터리와 더미키만 사용한다. 개발 중 사용자 실제 키 초기화나 실제 주문은 실행하지 않았다.
