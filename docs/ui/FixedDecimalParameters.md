# 전략 파라미터 행과 고정 소수 입력 (2026-10-04)

기존 사용범위 **백테스트7 / 공통51 / 온라인0**과 계산·기본값·SQLite 키는 유지한다. 온라인 전용 새 파라미터는 없고, 공통 설정은 검증된 낙주 실시간 실행에도 적용한다.

## 라벨과 명시적 행

라벨은 OversoldConfig의 ParameterAttribute에서 사용자 요청 51개를 변경했다. 카드·Tooltip·상세 도움말은 같은 ParameterCatalog 결과를 사용한다. 분야는 종목 선별·급락, 이동평균선, 과거 고점, 근사 매물대, 지지 군집, 반등 확인, 분할매수, 손절, 익절, 추적 손절, 보유·재진입이다.

`OversoldParameterLayout.Rows`는 26개의 3칸 행을 정의한다. 평균 거래대금 기간/최소, 중·단기 기간/기준, RSI와 거래량의 ON/기간/기준, TP1·TP2의 ON/기준/비율 등을 같은 행에 둔다. 지지 이탈과 가격자료 검증 모드는 독립 행이다. 전체 59개 필드와 빈칸19개가 있으며 null 칸은 Visibility.Hidden으로 공간을 유지한다. 다음 분야의 항목을 채워 넣지 않는다.

입력칸은 정수·소수·목록 모두 **180×32 DIP, Padding 8/4**로 통일했다. 3열은 남은 가로폭을 균등 분배하고 설명은 줄바꿈한다. 창 최소 폭의 1,160 및 1,540에서 가로 잘림과 세로 스크롤을 검사했다. 기존 오른쪽 세 탭의 최소14 정책을 유지한다.

## 표시와 원값

- decimal 파라미터는 편집 전후와 focus/blur 모두 소수 둘째 자리다. 정수 기간·횟수는 정수 및 천 단위 쉼표를 유지한다.
- EntryRatios는 `40.00, 30.00, 30.00`처럼 **각 비율을 따로** 표시한다. 목록 쉼표는 천 단위 구분자로 파싱하지 않는다. MaxEntries에 맞춰 길이를 바꿀 수 있고 합100 및 길이 검증을 유지한다.
- MovingAveragePeriods는 `120,240,480,999`처럼 정수 목록을 유지한다. enum/bool/시점 JSON에는 소수 편집 동작을 적용하지 않는다.
- ParameterField.Value는 원값, InputText는 편집 표시값이다. 저장된 `0.015`는 `0.02`로 보이지만 **보기·focus·blur·그대로 저장만으로 원값을 변경하지 않는다**. Tooltip에 정확한 저장값과 표시 반올림 여부를 설명한다.
- 사용자가 숫자를 덮어쓰거나 선택 치환/붙여넣기/삭제한 필드만 새 두 자리 값으로 저장한다. 다른 필드나 전체 프리셋을 일괄 반올림하지 않는다.

## 입력 동작

| 동작 | 처리 |
|---|---|
| 숫자 입력 | 정수부는 삽입, 소수점 뒤 두 자리만 덮어쓰고 한 자리 전진 |
| 커서가 소수점·천 단위 쉼표·부호 앞 | 소수점 바로 앞은 정수 삽입(1|.00 → 12|.00). 쉼표는 재그룹화, 부호는 보존 |
| 소수점 키 | 현재 값의 소수 첫째 자리로 이동; 중복 소수점 생성 없음 |
| 소수 둘째 자리 뒤 입력 | 거부 및 안내 |
| 선택 영역에 숫자 입력 | 선택 부분 치환 후 두 자리 형식 유지 |
| 정수 자릿수 늘리기 | 정수부에서 일반 숫자 입력으로 자릿수 증가. 소수점 키를 누르면 소수부로 이동 |
| 목록 길이 변경 | 전체 선택 후 `50,50` 등 붙여넣기; 항목별 두 자리 표시 |
| 붙여넣기 | 올바른 숫자/쉼표 형식 검사. **소수 셋째 자리 이상은 거부**하고 기존 값 유지; 반올림 삽입하지 않음 |
| Delete/Backspace | 정수 자리 삭제, 소수 자리0으로 지우기; 소수점 유지 |
| 전체 선택 후 삭제 | 빈 입력을 유지하고 검증 오류 표시. 0으로 묵시 저장하지 않음 |
| 음수 부호 | 현재 값의 부호 전환, -0.00 및 입력 중 '-' 유지; 실제 허용 범위는 기존 validation |
| Home/End/방향키 | TextBox의 커서 이동 유지 |
| 잘못된 문자/IME | 소수 입력창에서 숫자가 아닌 입력 거부. 숫자 전용 창에만 IME 비활성화 |
| 목록 구분자 | 단독 삭제로 합쳐지지 않음. 선택/전체 붙여넣기로 목록을 명시적으로 수정 |

`FixedDecimalEdit`는 표시·자리 편집을 담당하는 순수 함수다. `FixedDecimalInput`은 WPF PreviewTextInput/PreviewKeyDown/Pasting/Cut 경로를 연결한다. 소수 3자리 이상 입력/잘못된 문자 거부 메시지는 해당 입력칸 아래에 나타난다. 입력 문법과 투자 범위/합계/교차 검증은 분리했다.
