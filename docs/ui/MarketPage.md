# 시장 현황

## 화면 목적
코스피·코스닥과 선택 종목의 당일 가격·등락, 최근 일평균 거래량을 확인한다.

## UI 기능
| UI | 기능 | 실행 코드 |
|---|---|---|
| 지수 카드 | 코스피·코스닥 현재 값과 하루 변화 | Kospi / Kosdaq |
| 선택 종목 카드 | 선택 종목 시세와 하루 변화 | StockQuote |
| 일평균 거래량 | 최근 확정 20거래일 평균과 기준일 | AverageVolume |
| 갱신 상태 | 마지막 조회, 오류, 지연 가능성 | MarketStatus |

## 동작 과정
시장 현황 탭 진입 및 5초 타이머 → RefreshMarket → 공개 시세 조회 → 카드 갱신.
요청 중에는 중복 조회를 건너뛴다. 다른 탭에서는 정기 조회를 멈추며 종료 시 취소한다. 실패한 값은 과거 시각과 함께 유지하고 갱신 실패를 표시한다. 종목을 바꾸면 이전 종목 카드는 비운다. 해외 종목의 가격 통화는 달러이며 국내는 원이다.

## 관련 코드
MainWindow.xaml, WorkspaceFeatures.cs, PublicMarketData.cs, WorkspaceModels.cs.

## 지수 카드 개편
국내/해외 탭형 버튼으로 국내 코스피·코스닥과 해외 다우존스·나스닥·S&P 500을 전환한다. 카드는 이름·정수 지수 값·▲/▼ 변화·등락률 배지·미니 선 차트·조회시각을 표시한다. 상승은 빨강, 하락은 파랑이다.
미니 차트는 Yahoo Finance가 제공하는 최근 거래일 5분 관측값이며 점선은 전일 종가다. 결측 값을 합성하지 않는다. 휴장 때는 마지막 거래일의 시각을 표시한다. 값과 차트의 제공처가 달라 차이가 날 수 있다. 국내 값은 5초마다, 국내 추이는 1분 간격으로 갱신한다. 해외는 5초 조회에서 값과 추이를 같이 받는다. 모두 시장 현황 탭을 보는 동안만 갱신한다. 차트 조회에 실패하면 오류를 표시한다.
관련 코드: IndexCards.cs / IndexSparkline / IIndexChartData / PublicMarketData.IndexHistory.
