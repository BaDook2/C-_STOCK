# 종목·차트 도구 배치

중앙 카드는 Grid의 Auto/Auto/*/Auto 행으로 헤더, 지표 범례·기간 선택, 가격/거래량/시간축, 자료 출처를 배치한다. 중앙에 ScrollViewer나 고정 차트 높이를 두지 않는다. 오른쪽 카드는 실제 계좌 주문 / 가상 계좌 주문 / 전략 백테스트 / 정기매수 백테스트의 4개 내부 탭이며 각 내용은 독립적으로 스크롤된다. 오프라인에서는 실제 계좌 주문 탭을 숨기고 가상 계좌 주문 탭을 기본 선택한다.

5·20·60·120봉 이동평균 표시 색은 주황·보라·초록·분홍이다. 일봉에서 각각 일 이동평균이고 주봉·월봉에서는 해당 주기의 봉 수이다. 전략 설정의 이동평균 기간은 변경하지 않았다. 관심그룹·관심등록·매매표시·지표 체크·봉 주기는 헤더 오른쪽이다. 좁은 창에서는 기간 버튼이 다음 줄로 줄바꿈된다.

전략 백테스트 탭은 저장 전략 ComboBox와 **백테스트** 버튼을 제공한다. 선택한 전략의 immutable 설정 snapshot을 공통 `IOversoldBacktestService`에 전달하며 직후 결과를 같은 탭에 유지한다. 정기매수는 같은 종목의 매일/매주/매월·시가/종가·투입액·초기금·수수료 설정, 계산 결과 카드와 평가곡선/매수 마커를 재사용한다. 결과는 테스트 기록에서 복원한다. 배당 자료 미제공 시 배당 재투자는 비활성이다.

실제 계좌 주문 탭은 온라인에서만 나타나며 수동 실제 주문과 실제 다중전략 진입만 둔다. 가상 계좌 주문 탭은 수동 가상 주문, 과거 재생과 `실시간 전략 모의매매` 진입을 모아 둔다. 이 버튼으로 연 다량 전략 창은 모의+실시간을 고정하여 실제 증권사 주문을 전송할 수 없고, 실제 계좌 탭에서 연 창은 연결 계좌의 실제 모드로 고정한다. 온라인에서도 전략·정기매수 백테스트 탭은 비활성화하지 않는다.

가격 차트는 마우스 왼쪽 버튼을 누른 채 좌우로 끌면 표시 범위를 이동한다. 매수·매도 표식은 기존보다 4 DIP 큰 14 DIP로 표시한다. 표식 글자 자체뿐 아니라 표식이 놓인 봉의 아무 위치나 한 번 클릭하면 그 봉의 가장 가까운 거래를 선택해 상세정보를 연다. 같은 봉에 여러 체결이 있으면 클릭한 세로 위치와 가장 가까운 표식을 선택한다.

1/3/6개월·1/3/5/10년 빠른 범위는 하나의 선택 그룹이며 선택된 범위를 파란색으로 표시한다. 일목균형표를 켜도 미래 표시 슬롯을 별도로 예약하지 않고 실제 봉 범위 안에서만 구름을 그리므로 확대·이동 뒤 오른쪽에 빈 띠가 생기지 않는다. 틱/분봉은 현재 연결 계좌가 해당 국내 이력 API를 제공할 때만 활성화되고, 틱 선택도 `원본 틱` 탭으로 이동하지 않고 중앙 차트를 갱신한다.

`실제매매 내역 표시`, `모의매매 내역 표시`, `백테스트 매매 내역 표시`는 서로 독립적이다. 선택한 항목은 하나의 차트 표식 목록으로 합쳐지므로 실제·모의·백테스트 체결을 동시에 비교할 수 있다. 백테스트는 현재 선택한 저장 결과의 실제 모형 체결시각·가격을 사용하고, 정기매수 표식은 기존 정기매수 도구 선택을 유지한다. 모든 표식은 틱·분·일·주·월의 해당 시간 봉과 기존 단일 클릭 상세를 재사용한다.

분봉/틱 이력 로딩은 15초 제한을 두고, 키움 연속조회는 최근 3페이지에서 차트를 먼저 완성한다. 우측 상단 `긴급중지`는 Busy 오버레이의 영향을 받지 않는 독립 명령이며, 진행 중인 UI 작업과 백그라운드 시세 요청을 취소하고 `ChartLoading`을 즉시 해제한다. 중지는 기존 보유 포지션을 임의 청산하지 않으며, 실계좌 미체결 취소 결과는 계좌 조회로 다시 확인한다.

읽기용 퍼센트는 소수 둘째 자리까지 표시한다. NumericDisplay.Percent + PercentPresentation은 TextBox의 원본 Text와 별도의 읽기 템플릿을 사용한다. 예: 저장/계산 0.015 → 비편집 표시 0.02 → 포커스 시 원본 0.015. 반올림된 표시에서 ConvertBack을 하지 않는다. 금액/수량은 천 단위 쉼표를 유지한다. 허용 범위 설명은 잘못된 경계를 안내하지 않도록 실제 최소·최대값의 정밀도를 보존한다.

검사: 1540×1040 및 1160×760 WPF 창에서 세 탭과 차트 실제 높이, 결과 위치, 수수료 binding 보존을 검사하고 tools-<width>-<tab>.png로 저장한다. 이는 자동 WPF 렌더 검사이며 물리 마우스 입력이나 다른 모니터의 DPI 이동 검사를 수행했다는 의미는 아니다.

관련: MainWindow.xaml, RecurringPurchasePanel.xaml, RecurringWorkspace.cs, CandleChart.cs, NumericDisplay.cs, MultiTradeUiTests.cs.

## 2026-10-03 오른쪽 패널 최소 글자 크기
`RightToolsPanel` 내부 세 탭은 최소 FontSize 14 WPF DIP이다. 14보다 큰 제목은 유지하고, 각 탭의 텍스트·입력·버튼·결과·템플릿 및 별도 창 트리의 달력/툴팁에도 `MinimumTextSize`를 적용한다. 다른 화면의 전역 스타일은 변경하지 않는다. 날짜 입력 폭과 탭 헤더 간격을 조정하고 좁은 창에서는 줄바꿈과 세로 스크롤을 사용한다.

전략 실행 버튼은 저장 전략을 선택하는 **백테스트**로 표시한다. 모의매매 재생은 수동 거래만 처리하고 과거 자동 전략을 실행하지 않는다. 정기매수 도구의 매일/매주/매월 설정과 결과·기록은 그대로 사용한다.

검사: `OnlyOversoldUiTests`의 right14-<width>-<tab>.png, 표시된 모든 TextBlock/Control의 최소14, 달력·도움말·다른 영역 폰트 보존 및 차트 높이 검사. 물리 입력/다중 DPI 이동은 미검증.

2026-10-04 전략 설정의 소수 입력은 FixedDecimalInput을 사용해 편집 중에도 두 자리를 유지하도록 변경했다. 이는 위의 focus 시 원정밀도 노출 방식과 다르며, 기존 원값은 Tooltip으로 알리고 무편집 저장 시 보존한다. 오른쪽 정기매수 등 다른 화면의 기존 입력 방식 및 최소14 정책은 유지한다. 상세: FixedDecimalParameters.md.
