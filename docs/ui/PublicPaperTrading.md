# 공개시세 실시간 가상매매

오프라인 테스트 → 종목·차트 → 가상 계좌 주문 → 실시간 가상 전략매매 설정에서 종목과 저장 전략을 선택한다. 공개시세 모의 분석 봉을 1~59분 또는 1~12시간으로 지정하고 실시간 모의매매 시작을 누른다. 전체 투자 한도는 가상 시드이며 종목 예산 합계는 이 한도를 초과할 수 없다. 국내 정규 연속매매 구간 09:00~15:20에 시작한다.

| UI | 동작 | 코드 |
|---|---|---|
| 공개시세 모의 분석 봉 | 오프라인 가상 전략 완성봉 단위. 스크리닝과 독립 | MultiTradeViewModel.PublicBarValue/PublicBarUnit |
| 실시간 모의매매 시작 | 공개 1분봉 준비 후 현재가 감시 | StartRealtimeMockMulti → StartPublicPaperMulti |
| 전체/선택 중지 | 가상 주문 생성 중단, 보유 자동청산 없음 | StopMulti |
| 모의매매 내역 표시 | 공개시세 모의매매 표식도 일·주·월 차트에 표시 | ReloadTradeMarkers |

팝업을 닫아도 Workspace의 실행은 유지된다. 전체 중지·긴급중지·종료 시 로컬 가상 미체결을 취소 완료한 뒤 폴링을 취소하고 기다린다. 보유 가상 포지션을 임의 청산하지 않는다. 목록·분석 봉은 저장하지만 재시작 때 자동 실행하지 않는다.

## 시세와 판단

오프라인 현재가는 네이버 KRX 공개 polling 응답이다. NXT 하위값을 섞지 않는다. 가상 다종목 실행은 서버가 보내는 pollingInterval을 따른다(2026-11-04 장중 7,000ms, 장 마감 후 70,000ms). 사용자가 보는 선택 종목 차트에는 별도 2초 빠른 조회를 적용한다. 화면은 새 응답을 즉시 반영하고 1초 타이머가 상태 표시를 보완한다. 가격이 같아도 관측 시각은 갱신될 수 있다.

공개 1분봉 이력을 14일 범위로 준비하고 실행 중에는 당일 이력을 분당 1회 읽는다. 실제 반환 구간만 사용하고 미완성봉/누락 구간을 채우지 않는다. 지표 준비 봉이 부족하면 해당 조건이 준비될 때까지 거래하지 않는다. 시간봉 등은 기존 StrategyBarAggregator로 집계한다.

OversoldLiveStrategy의 공통 진입·분할매수·청산 로직을 사용한다. 공개 OHLCV에는 정확한 봉별 거래대금/과거 종목상태/뉴스위험이 없어, 이 모의 실행에만 거래대금 OHLC 평균×거래량과 일반주식·관리 아님·수동 악재 제외 가정을 사용한다. 알려진 ETF/ETN/SPAC·정지/관리 상태는 시작을 차단한다. 이 가정은 화면과 저장 plan에 표시되며 실계좌 LiveStrategyBatch에서 거부된다.

## 모의 체결

완성봉에서 신호를 계산한 뒤 새 공개 관측에서 가상 주문을 접수하고, 그보다 뒤의 새 관측에서만 체결한다. 지정가는 관측 가격이 주문가격을 통과해야 하며, 관측 사이 누적거래량 증가분×참여율로 수량을 제한한다. 첫 관측/동일 관측/누적량 증가 없음은 체결 수량을 만들지 않는다. 20초 지연·연결 실패는 새 가상 주문을 중단한다.

표식 source는 공개시세 모의매매다. 내부 관측용 매칭 이벤트는 원본 체결 DB나 Raw Tick 차트에 기록하지 않는다. 실제 호가·장중 체결 순서·개별 체결량을 복원하지 않으므로 실체결 재현 결과로 해석하지 않는다.

## 온라인

연결 증권사의 현재가 REST/지원 WebSocket을 사용한다. 키움은 OHLCV가 있는 현재가 응답, 다른 계좌는 기존 CurrentPrice 계약을 사용한다. 실패 시 공개 가격으로 바꾸지 않는다. 가격만 제공되는 계좌는 기존 당일봉 거래량을 유지하고 가격·고저만 갱신한다. 온라인 실시간 가상 전략 피드는 기존 키움 지원 범위다.
