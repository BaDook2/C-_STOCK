## 유지할 제한

메모리 시세·원본 틱은 앱 종료 시 사라진다. 테스트 기록의 당시 봉/판단 자료는 DB에 남는다. 예전 캐시/틱을 삭제하거나 DB 파일 용량을 줄이지 않았다. 실계좌 원가/비용이 없어 계산할 수 없는 체결 손익은 미확인이다. 만료 토큰/연결 실패는 기존 broker 처리와 주문 전 재검증을 따른다. 모드 왕복1.6~3.4ms는 fake broker 측정값이다.

- [!] 이전 DB 최초 손상 유발 사건 미확정. 승인된 복구와 원본 보존·손상 state13개/틱6건 복구 미확인 내역은 docs/verification/ProgressiveScreening-2026-11-07.md, 실제 경로 대조는 docs/maintenance/Storage.md.
