## 원본 WPF 기준 디자인 후속 변경

상세 지도·검증은 docs/UI_PARITY.md. MainWindow.axaml/Styles/StockTheme.axaml과 Views의 OrderToolsPanel, ScreeningSettings, AccountPanel, HistoryPanel, MarketPanel, WatchPanel을 사용한다. PresentationWorkspace는 화면 전용 속성이다. StockChart.Appearance.cs는 기존 ScottPlot의 축/표시 지표만 담당한다. SecretInput/StrategyNumberBox의 TextBox StyleKeyOverride는 실제 입력칸 렌더링에 필수다. DesignChecks.cs는 별도 --design 모드로 실행되며 verify 스크립트에 포함된다.
