# Stock v0.1.16 · Windows Avalonia

Windows 배포 UI를 Avalonia로 전환한다. 원본 WPF 소스와 공통 전략/백테스트 엔진은 보존한다. 다운로드는 Stock.exe 한 파일이며 .NET 별도 설치가 필요 없다.

- 익절 빨강/손절 파랑, 실제 한글 표식/단일 클릭·거래 상세 선택, 포인터 줌·양방향 팬·달력/표 UI를 검수했다.
- 키/기본 계좌를 OS 보안 저장소에 보관하고 성공 인증·계좌 확인 후에만 저장한다. 원본 WPF 키/DB를 자동 복사하지 않으므로 새 앱에서 계좌를 연결해야 한다. 개인정보는 배포 파일에 포함하지 않는다.
- 실제 수동 주문은 기본 잠김이고 활성화·건별 확인·한도/최종 계좌/중지 검사를 거친다. 취소 접수·체결 접수를 완료로 만들지 않는다. 확인된 실제 체결만 계좌 scope에 표시한다.
- 실제 전략 실행은 기존 키움 국내 batch/피드/체결 대사를 재사용한다. 검증된 시점별 종목·위험·시장 세션·실제 거래대금 입력이 필요하다. 가상 가정/추정 거래대금으로 실계좌를 실행하지 않는다. 다른 브로커의 수동 주문 지원과 구분한다.
- 일봉 가상 전략은 종가 신호 다음 거래일의 신선한 관측 이후 주문하고, 더 늦은 관측의 보수적 유동성·가격 규칙으로 체결한다. 공식 시가 체결을 보장하지 않는다. 일 손실 기준을 거래일별로 보존한다.
- 가상 원장·분할/익절/최고가·군집/반등·미체결/보유를 원자적으로 보관하고 무결성·현금/수량을 대사한다. 복원은 정지 상태이고 보호 감시 재개도 신규/추가매수 OFF다. 원본 틱/관측 캐시는 저장하지 않는다.
- 표의 표시용 숫자 변환이 원본을 바꾸지 않도록 OneWay를 명시했다. 원본 값과 실제 표시값을 함께 검사한다.

검증: Release0경고0오류, Core192/Avalonia273/디자인18/WPF1652, 실제공개28, 정상 EXE 검색·재실행4회 및 실제 공개자료 백테스트/마우스/달력/손익색 검증. 주문 검사는 가짜 계좌/피드만 사용했으며 실제 돈 주문은0건이다.

Mac arm64/x64 소스 교차 빌드는 성공했다. 실제 Mac 실행·Keychain 권한/잠금·트랙패드·서명/공증 및 실제 증권사 API 검증은 별도이며 이 Windows 릴리즈에서 확인한 것으로 표시하지 않는다. Mac 바이너리는 첨부하지 않는다.

빌드 경로 검증: Mac 번들 제외 규칙을 실제 번들 이름으로 제한하고 원본 WPF 신규 소스가 Git checkout에도 포함되도록 수정했다. v0.1.15는 CI 실패로 공개되지 않았으며 기존 태그를 덮어쓰지 않았다.
